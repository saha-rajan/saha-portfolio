# Case Study: Arizona Yoga Co.

## Project Metadata
* **Project Name**: Arizona Yoga Co. - Website UX Redesign
* **Role**: UX Designer & Researcher
* **Tools**: Heuristics, Surveys, Personas, Figma
* **Timeline**: Second Semester
* **Platform**: Desktop Website / Responsive Redesign

## Overview & Problem
Despite offering valuable yoga programs and a unique donation-based pricing model, the Arizona Yoga Co. website created significant friction for users attempting to complete core tasks. The redesign focused on UX research and a website redesign to eliminate that friction and improve usability.
